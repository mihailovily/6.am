# 6.am — чек-лист интерфейса

Дополнение к [дизайн-системе](DESIGN_GUIDE.md) и [ревью](DESIGN_REVIEW.md). Это сценарии приёмки, а не отчёт о пройденных тестах. В ревью от 2026-09-07 браузерная проверка не выполнена из-за ошибки запуска CDP.

## Матрица

Для каждой строки проверить `/` и `/time.html#clock`, `#stopwatch`, `#pomodoro`, `#settings`.

| Viewport, CSS px | Назначение | Статус |
| --- | --- | --- |
| 1440×900, 1024×768 | Desktop, иерархия, высота панелей | Не проверено |
| 761×900, 760×900 | Перестроение Settings и вкладок | Не проверено |
| 601×900, 600×900 | Плотность и footer | Не проверено |
| 381×812, 380×812, 375×812 | Узкая навигация | Не проверено |
| 320×568 | Нижняя тестовая ширина | Не проверено |
| 812×375 | Landscape и fullscreen | Не проверено |

320px — тестовый сценарий, а не гарантия, объявленная кодом. Дополнительно проверить 200% zoom и увеличение текста. Desktop-панели сохраняют минимум 580px; mobile — высоту по содержимому.

## Главная и оболочка

- [ ] Hero, описания и Coming soon не перекрываются на узких экранах.
- [ ] Time открывается всей строкой; Tasks/Rituals не ведут себя как ссылки.
- [ ] Hover не обрезает содержимое; keyboard focus виден на всей ссылке.
- [ ] Логотип возвращает домой; footer читаем и не накладывается на контент.
- [ ] Локальный Geist загружается; fallback не делает цифры нечитаемыми.

## Навигация

- [ ] Без hash открывается Clock после инициализации; прямые hash-ссылки открывают нужные панели.
- [ ] Accessibility tree содержит четыре именованные вкладки и именованную панель, включая mobile.
- [ ] Selected, `aria-selected`, `tabindex` и видимая панель согласованы.
- [ ] Tab, Shift+Tab, стрелки и Home/End работают; скрытые панели не получают фокус.
- [ ] Running dot соответствует запущенному таймеру и отличается от selected.

## Clock

- [ ] 24-hour и 12-hour с AM/PM полностью помещаются на 320/375px.
- [ ] Длинная дата, часовой пояс и Custom label до 80 символов не ломают композицию.
- [ ] Обновление цифр не двигает соседние элементы; шкала остаётся вторичной.
- [ ] Сохранённые настройки отражаются после перезагрузки.

## Stopwatch

- [ ] Initial показывает Start и выполнимую подсказку; mobile не предлагает скрытый Lap.
- [ ] Running показывает Pause/Lap; paused — Resume/Reset; disabled соответствует состоянию.
- [ ] Первый круг заменяет empty state таблицей; много кругов прокручиваются внутри списка со sticky-заголовком.
- [ ] Длинное время и сотые не обрезаются; Reset возвращает начальную композицию.

## Pomodoro

- [ ] Фазы синхронизируют selected, `aria-pressed`, заголовок, время и прогресс.
- [ ] Start/Pause/Resume и Reset соответствуют реальному состоянию.
- [ ] Смена работающей фазы запрашивает подтверждение; отмена сохраняет состояние.
- [ ] Сессия, проценты и уведомление завершения читаемы и не вызывают нежелательных скачков.
- [ ] Завершение проверено с auto-start и без него; звук не является единственным сигналом.

## Settings

- [ ] Desktop-колонки переходят в одну; четыре числовых поля — в 2×2.
- [ ] На 761/820px подписи, единицы и значения Sessions не обрезаются.
- [ ] Focus виден на всех полях/switch, особенно `.number-field`, и не обрезан.
- [ ] Пустые/дробные/выходящие за диапазон значения и неверный пояс дают понятную ошибку.
- [ ] Успех и ошибка различимы и объявляются через status/alert.
- [ ] Каждая форма сохраняется своей кнопкой; reload восстанавливает значения.
- [ ] Недоступный localStorage даёт сообщение о временном применении настроек.

## Fullscreen, движение и контраст

- [ ] Три режима входят/выходят через кнопку и Escape; проверены нативный API и fallback.
- [ ] Header/footer скрыты; выход доступен и правильно подписан.
- [ ] Landscape, много кругов и zoom 200% не вызывают пересечений цифр и действий.
- [ ] После исправления reduced motion нет перемещений панелей/сервисов и smooth scroll.
- [ ] Измерены normal/hover/selected/focus/disabled, особенно границы полей.
- [ ] Проверены bounding boxes: `overflow-x: clip` не маскирует обрезание.

## Техническая проверка

После UI-изменений:

```bash
npm run build
npm run check
npm run lint:css
npm test
npm run smoke
npm run preview
```

Production preview проверить по той же матрице. Эти команды не заменяют визуальную проверку и accessibility tree. Для изменений только Markdown достаточно сверить описания с исходниками, проверить локальные ссылки и diff.

Для дефекта записать маршрут, viewport, состояние, шаги, ожидаемый и фактический результат; скриншот подписать теми же параметрами. Отмечать `[x]` только после выполнения; непроверенное оставлять открытым с причиной.

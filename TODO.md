Для работающих счётчиков предпочтительно восстановление по абсолютным timestamps, а не по числу пропущенных ticks.
  - **Готово, когда:** reload и повторное открытие вкладки продолжают оба счётчика с корректным прошедшим временем; повреждённый/устаревший snapshot безопасно сбрасывается; есть unit-тесты восстановления.

  - **Решение:** для выбранного этапа сделать обработчик no-op; при смене этапа во время отсчёта запрашивать подтверждение или требовать явной остановки. Состояние этапа передавать семантически через `aria-pressed` либо radio-group.

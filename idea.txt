Создай сайт-проект 6.am, вдохновленный эстетикой winter arc и на данный момент состоящий из двух страниц:
1. Основная index.html, содержащая минималистичное оглавление-ссылки на грядущие полезные сервисы внутри экосистемы

2. Часы-секундомер-помодоро в одной странице time.html

Идеи, визуальный стиль и функционал бери из base.html

Получившийся проект должен иметь весь функционал base.html, при этом быть более интерактивным, т.к в base не работает часть интерактивных функций

Полученный проект должен быть гибким, модульным и легко масштабируемым, простым в сборке (вероятно, через npm run build). Для реализации можно использовать pug, typescript, html, css, js и прочие технологии и фреймворки, согласованные со мной

В будущем планируется собирать все через GitHub ci/cd и заливать на cloudflare pages, распространяя исходный код свободно

После реализации задания составь инструкцию по деплою и сборке проекта, GUIDE.md

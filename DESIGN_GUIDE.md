# 6.am — текущая дизайн-система

Срез от 2026-09-07, исходный коммит `976056c`. Гайд описывает реализованный интерфейс по CSS, Pug и JavaScript. Замечания и ограничения проверки — в [дизайн-ревью](DESIGN_REVIEW.md), сценарии приёмки — в [чек-листе](DESIGN_CHECKLIST.md). Рекомендации из ревью пока не реализованы.

## Характер и язык

6.am — спокойный набор инструментов для продуктивной работы. Главная — оглавление; Time объединяет Clock, Stopwatch, Pomodoro и Settings. Tasks и Rituals представлены некликабельными строками `Coming soon`.

Визуальный язык: почти чёрный фон, тонкие границы, светлая типографика, холодный голубой акцент, крупные показания времени. На главной доминирует двухстрочный `Less noise. More focus.`, в Time — цифры или форма настроек. Теней, градиентов и иллюстраций в текущих стилях нет. Капсула навигации сочетается с почти прямоугольными панелями и кнопками.

Язык продукта — английский (`html lang="en"`), документация — русский. Намеренно иноязычный фрагмент интерфейса должен иметь свой `lang`. Название — **6.am**; Winter Arc осталось в совместимом ключе старых настроек.

## Типографика

Базовый текст — **Arial, sans-serif**, `16px/1.5`. **Geist Sans** применяется только к `.timer-digits`, включая Clock и Stopwatch. **Consolas, monospace** — к кодам, сессиям, индексам сервисов, полям и таблице кругов. Весь сайт не набран Geist.

| Роль | Текущие параметры |
| --- | --- |
| Логотип | `1.5rem`, вес 600, tracking `-.06em`; mobile Time — `1.25rem` |
| Hero | `clamp(3.4rem, 8vw, 7rem)`, строка 1.02, tracking `-.08em`, вес 400 из общего `h1` |
| Заголовок Time | `1.25rem`, вес 400, tracking `-.025em` |
| Базовые цифры / Pomodoro | `clamp(5rem, 10.1vw, 9rem)`, Geist 300, tracking `-.065em`, строка 1.35 |
| Clock | `clamp(4.8rem, 13vw, 12rem)`, остальные свойства базовых цифр |
| Сотые Stopwatch | `.44em` от цифр, tracking `-.05em`, приглушённый цвет |
| Settings h2 | `1rem`, вес 500 |
| Вкладки, подписи полей, фазы | `.875rem` |
| Primary CTA | `.9375rem`, вес 500 |
| Feedback, пояснения | `.8125rem`, строка 1.6 |
| Eyebrow, код, сессия | `.75rem` monospace, tracking `.15em` |

Цифры используют `tabular-nums` и `white-space: nowrap`: значения не меняют ритм при обновлении, но длинное время требует проверки на узких экранах.

## Компоненты и состояния

| Компонент | Контракт |
| --- | --- |
| Логотип | Ссылка домой с `aria-label`; header главной — partial, Time — отдельная разметка |
| Сервис | Time — ссылка всей строкой; будущие сервисы — `article` со статусом |
| Вкладки | `tablist`, ссылки с `role="tab"`, `aria-controls`; selected — `aria-selected="true"`, заливка и светлый текст |
| Фазы | Кнопки в `role="group"`; `.selected` и `aria-pressed`, заливка и рамка |
| Primary | От 200×54px, padding `14px 26px`, светлая заливка; hover белый; текст меняется по состоянию |
| Icon / text button | Высота от 48px, рамка 1px; icon шириной от 48px; отдельного hover-background нет |
| Fullscreen | 40×40px, absolute top/right 20px, меняющиеся `aria-label` и `title` |
| Числовое поле | Label сверху, единица внутри рамки справа, input от 45px; минуты 1–180, сессии 1–12 |
| Clock-поля | Label сверху, input от 45px; Time zone с datalist, Custom label до 80 символов |
| Switch | Checkbox, 42×24px, бегунок 16px; checked меняет цвет и сдвигает бегунок на 18px |
| Feedback | `role="status"`, минимум 22px, голубой текст; ошибка — `role="alert"`, `--error` |
| Running dot | Круг 5px рядом с вкладкой запущенного таймера |
| Empty / laps | Подсказка до появления кругов; затем таблица Lap / Lap time / Total |

После инициализации JS `/time.html` открывает Clock, hash выбирает режим. Исходный Pug до инициализации показывает Pomodoro. JS синхронизирует `hidden`, `aria-selected` и roving `tabindex`; стрелки влево/вправо, Home/End переключают и фокусируют вкладки.

На ширине до 760px Stopwatch сначала показывает только Start, при работе — Pause и Lap, на паузе — Reset и Resume. Подсказка `Use the flag to record a lap.` остаётся и до появления Lap — это дефект из ревью, а не рекомендуемое правило.

SVG — без заливки, `currentColor`, круглые концы и соединения: обычно 20×20px, stroke 1.6; fullscreen — 16×16px, stroke 1.7. JS заменяет исходные символы Reset/Lap на SVG.

## Fullscreen и движение

Нативный Fullscreen API имеет fallback внутри страницы. `.time-fullscreen` скрывает header/footer, снимает рамки/радиусы, задаёт фон страницы и `100vh`. Цифры — `clamp(5rem, min(14vw, 28vh), 16rem)`, строка 1.12. У Stopwatch цифры абсолютно по центру, действия снизу, круги выше цифр с ограничением высоты. Выход — кнопка и Escape.

Появление панели: **220ms**, opacity и сдвиг 8px. Вкладки, footer, switch: **150ms**. Hover сервиса: **180ms**, включая padding. Включён smooth scroll. Правил `prefers-reduced-motion` сейчас нет.

## Доступность и расширение

Реализованы label-связи полей, ARIA-состояния вкладок/фаз, статусные сообщения, имена icon buttons и скрытие неактивных панелей. Общий focus — outline 2px акцентного цвета с отступом 4px; Clock-поля — 3px. Числовые поля подавляют этот outline, а мобильные вкладки скрывают единственный текст имени — оба дефекта описаны в ревью.

При расширении:

1. Переиспользовать оболочку и компоненты; специфичные стили ограничивать классом страницы.
2. Держать цветовые значения в `tokens.css`, выбирать существующие роли. Новые шкалы размеров вводить отдельной согласованной миграцией.
3. Сохранять иерархию режимов времени: заголовок → значение → контекст → управление.
4. Давать действиям устойчивые доступные имена, видимый keyboard focus и текстовое объяснение состояния.
5. Обновлять Pug ID, JS-селекторы и ARIA-связи совместно: ID являются контрактом.
6. Проходить [чек-лист](DESIGN_CHECKLIST.md); не переносить замечания текущего кода в новые компоненты как норму.
7. Обновлять гайд вместе с визуальными изменениями. Предложение из ревью становится фактом только после изменения и проверки интерфейса.

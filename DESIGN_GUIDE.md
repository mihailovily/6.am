# Winter Arc — дизайн и правила расширения

## Характер интерфейса

Winter Arc — спокойный инструмент для работы со временем. Визуальный язык должен создавать ощущение тишины, точности и присутствия: минимум декоративного шума, крупные показания времени, ясная иерархия и аккуратные состояния интерфейса.

## Дизайн-система

- **Фон:** почти чёрный `#08090b`; панели — `#0d1013` и `#101316`.
- **Текст:** основной `#edf2f5`, вторичный `#cbd2d8`, приглушённый `#9ca6ae`.
- **Акцент:** холодный светло-синий `#c7d8e3`; использовать для активных состояний, прогресса и фокуса.
- **Композиция:** широкий воздух, выравнивание по сетке, одна доминирующая задача на экране.

## Правила интерфейса

1. Сохраняй тёмную нейтральную основу и холодный акцент; новые цвета добавляй только при ясной функциональной необходимости.
2. Крупные значения времени должны оставаться главным визуальным объектом; вторичные подписи не должны конкурировать с ними.
3. Любое интерактивное состояние должно быть понятно без цвета: добавляй текст, линию, форму или изменение контраста.
4. Проверяй мобильную версию при добавлении новых панелей
